# Biblioteca Online

API desenvolvida para o projeto final da Unidade 3, com autenticação JWT, rotas protegidas, deploy no Render e documentação com Swagger.

## Tecnologias

- Node.js
- Express
- JWT
- CORS
- Swagger
- Render

## Link da API

https://biblioteca-online-bxyv.onrender.com
